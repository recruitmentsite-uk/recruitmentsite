STEP 3 — PASTE INTO CLOUDFLARE DNS (after NS propagates)
═══════════════════════════════════════════════════════════════════

Cloudflare → Websites → recruitmentsite.co.uk → DNS → Records

Add or edit these. For website records set Proxy status to DNS only (grey cloud).

--- Website (Vercel) ---
Type    Name    Content                 TTL     Proxy
A       @       76.76.21.21             Auto    DNS only (OFF)
CNAME   www     cname.vercel-dns.com    Auto    DNS only (OFF)
CNAME   *       cname.vercel-dns.com    Auto    DNS only (OFF)

--- Email (Blossom/cPanel — DO NOT CHANGE VALUES) ---
Type    Name    Content                 Priority    TTL
MX      @       mx1.cloudhosting.uk     10          Auto
MX      @       mx2.cloudhosting.uk     20          Auto
A       mail    185.199.220.91          —           Auto

--- Email authentication ---
Type    Name      Content
TXT     @         v=spf1 +a +mx +ip4:185.199.220.91 include:relay.k.io ~all
TXT     _dmarc    v=DMARC1; p=none;

--- Resend (after nameservers are on Cloudflare) ---
Do NOT add these manually if using Domain Connect:
  1. https://resend.com/domains → Add Domain → recruitmentsite.co.uk
  2. Click "Sign in to Cloudflare" → Authorize
  3. Records on "send" subdomain + resend._domainkey are added automatically

If adding manually from Resend dashboard, use only the host name (not full domain):
  Type    Name                  Content (from Resend)
  MX      send                  [Resend MX value]     Priority 10
  TXT     send                  [Resend SPF value]
  TXT     resend._domainkey     [Resend DKIM value]

Delete any conflicting records Cloudflare imported (old apex A to 185.199.220.91
for the website — keep mail A record on "mail" only).
